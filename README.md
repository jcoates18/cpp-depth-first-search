# C++ Depth-First Search & Graph Traversal

A C++ application that demonstrates graph representation and traversal using depth-first search (DFS). This project was developed in Microsoft Visual Studio as part of my advanced C++ coursework.

## Features

- Represents graph data using object-oriented programming
- Implements depth-first search (DFS)
- Tracks visited vertices during graph traversal
- Uses adjacency relationships to represent connections between vertices
- Uses C++ vectors and pointers for graph management
- Demonstrates recursive graph traversal

## Concepts Demonstrated

- C++
- Object-Oriented Programming
- Graph Data Structures
- Depth-First Search
- Recursion
- Vectors
- Pointers
- Algorithms

## Development Environment

- C++
- Microsoft Visual Studio

## About This Project

This project was created to apply advanced C++ concepts to graph data structures and traversal algorithms. It strengthened my understanding of how graphs can be represented programmatically and how depth-first search can be used to systematically explore connected vertices.
